## 📋 Описание задачи

Разработать масштабируемую архитектуру видеохостинга с поддержкой:

| Возможность | Описание |
|:-----------:|:---------|
| 📤 **Загрузка** | Поддержка видеофайлов до **50 ГБ** |
| 🎞️ **Транскодирование** | Автоматическая генерация битрейтов **360p → 2160p** |
| 🌐 **Стриминг** | Доставка контента через **CDN** |
| ⚡ **Асинхронность** | Обработка через **очереди сообщений** |
| 💾 **Хранение** | Отказоустойчивое **S3-хранилище** |

## 🏗️ Архитектурные решения

### ⚡ Асинхронная обработка видео
Использование очереди сообщений (Message Broker) для асинхронной обработки транскодирования. Пользователь не ждёт завершения обработки — система уведомляет о готовности.

### 💾 Хранение видео
- **S3-хранилище** для оригиналов и битрейтов
- **Репликация данных** для отказоустойчивости
- **CDN** для географического распределения контента

### 🎞️ Транскодирование
Автоматическая генерация битрейтов 360p, 480p, 720p, 1080p, 1440p, 2160p с помощью **FFmpeg**.

### 4. Диаграмма взаимодействия (Sequence Diagram)
**Сценарий: Загрузка видео на видеохостинг**

![Sequence Diagram](ИДЗ_Архитектура_Sequence Diagram_5.png)

#### 🔄 Процесс загрузки
| Шаг | Этап | Описание |
|:---:|:----:|:---------|
| 1️⃣ | **Авторизация** | Проверка токена, создание записи о видео в БД |
| 2️⃣ | **Загрузка файла** | Получение presigned URL, загрузка в S3 чанками |
| 3️⃣ | **Асинхронная обработка** | Задача на транскодирование через Message Broker |
| 4️⃣ | **Обновление статуса** | Изменение статуса видео на «готово» |

#### 🧩 Компоненты системы
| Компонент | Роль |
|:---------:|:-----|
| **k8s (API)** | API Gateway |
| **k8s (Auth)** | Auth Service |
| **k8s (Services)** | Video Service, Upload Service, Notification Service |
| **Message Broker** | Брокер сообщений (RabbitMQ/Kafka) |
| **Transcoding** | Сервис транскодирования |
| **DataBase** | База данных |
| **S3** | Объектное хранилище |

## 🛠️ Технологический стек

| Категория | Технология | Обоснование |
|:---------:|:----------:|:------------|
| 🚪 **API Gateway** | Kong / NGINX | Маршрутизация, rate limiting |
| 🔐 **Auth Service** | Node.js + JWT | Быстрая аутентификация |
| 🎬 **Video Service** | Go | Высокая производительность |
| 📤 **Upload Service** | Node.js | Работа с потоками |
| 🎞️ **Transcoding** | FFmpeg + Python | Стандарт индустрии |
| 📨 **Message Broker** | RabbitMQ / Kafka | Надёжные очереди |
| 🗄️ **Database** | PostgreSQL | ACID, надёжность |
| 🪣 **Storage** | AWS S3 / MinIO | Объектное хранилище |
| 🌍 **CDN** | CloudFront / CloudFlare | Глобальная доставка |
| ☸️ **Orchestration** | Kubernetes | Масштабирование |

## 📈 Ключевые требования

| Требование | Описание | Приоритет |
|:----------:|:---------|:---------:|
| ✅ **Доступность** | Система должна быть доступна 24/7 | 🔴 Высокий |
| 🔄 **Бесперебойность** | Отказоустойчивость при выходе серверов из строя | 🔴 Высокий |
